# Extracted Lean (snapshot)

`Hylo.lean` is what Aeneas produced for `explore/hylo` on 15 November 2026, via
`earth +extract --AENEAS_TARBALL_URL=…/build-7a8e111/aeneas-linux-x86_64.tar.gz`
(gilescope/aeneas release `build-7a8e111`, Lean 4.34.0). Extraction started from the sixteen
named algorithms (`--start-from`), so this is the per-shape core and what it uses; the
GAT-based generic API is not here by design.

It is a snapshot for reading. The live copy is regenerated by `earth +verify` into
`formalism/verify/FormalismVerify/Extracted/` (git-ignored) and checked by `lake build`.
