# Extracted Lean (snapshot)

`Hylo.lean` is what Aeneas produced for `explore/hylo` on 17 November 2026, via
`earth +extract --AENEAS_TARBALL_URL=…/build-4797bb9/aeneas-linux-x86_64.tar.gz`
(gilescope/aeneas release `build-4797bb9`: GAT-lite plus a model of `Vec::pop`, which earlier
builds extracted as an axiom).
Extraction starts from the sixteen named algorithms plus the `hylo::dp` roots (`solve_scheme`,
`solve_bits`, `eval_ones`, `delta_*`; `--start-from`), so this is the per-shape core and what it
uses; the GAT-based generic API is not here by design. The bodies of the dependency crate's
`expr.rs`, `scheme.rs`, `semiring.rs` and `instances/bits.rs` are translated too
(`--include=formalism::expr::_ --include=formalism::scheme::_ --include=formalism::semiring::_
--include=formalism::instances::bits::_`): Charon keeps a dependency's bodies opaque unless
asked, and the refinement proofs need them.

It is a snapshot for reading. The live copy is regenerated by `earth +verify` into
`formalism/verify/FormalismVerify/Extracted/` (git-ignored) and checked by `lake build`.
